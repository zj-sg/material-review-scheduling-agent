# 合成业务资料

`api-data.json` 是可公开的合成素材、审核规则和初始化排期，供 HTTP 服务默认读取。
M01 为正常素材，M02 缺少授权状态，M03 命中阻断词，M04 授权状态未知；均不是实际业务或候选人资料。

`rules` 定义渠道、必填字段、禁用表述、时长与查询步长。`initial_state` 包含素材、补查资料及首次初始化的正式排期。
已有 SQLite 表不会被这个文件覆盖；正式占用以数据库为准。

`examples/api-data.json` 保留为早期演示兼容副本；新环境默认配置使用本目录文件。
数据库、API Key、临时运行与缓存不提交。`.gitignore` 仅允许本说明和合成 JSON 进入 Git。
